# Data Directory

## Purpose

This directory contains the datasets used for customer churn analysis
and revenue-at-risk estimation.

## Directory Structure

- `raw/`: Original datasets, preserved without modification.
- `processed/`: Cleaned or transformed datasets generated during analysis.

## Data Handling

- Raw and processed data files are excluded from Git by default.
- Do not commit sensitive customer information or credentials.
- Document the dataset source, license, schema, and any transformations.
- Keep raw data unchanged so the analysis can be reproduced.

## Dataset Status

The dataset source and exact file version have not yet been documented.
These details will be recorded after the dataset is confirmed.
